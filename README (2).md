# 🚀 Huzaifa Ahmed Bhutto — Portfolio

A modern, dark-themed personal portfolio website built with vanilla **HTML, CSS, and JavaScript**. Showcases my projects, skills, and journey as a Mobile App & Full Stack Developer.

**🔗 Live Site:** [huzaifaahmedbhutto.vercel.app](https://huzaifaahmedbhutto.vercel.app/)

---

## 📖 About

This is a fully custom-coded portfolio landing page — no frameworks, no templates, built from scratch to reflect a clean, futuristic "system UI" aesthetic. It highlights my work as a Computer Science student who builds real, shipped projects instead of just tutorials.

---

## ✨ Features

### 🎨 Design & UX
- **Animated boot-up loader** — a "system starting" style intro screen with orbiting rings, live stats, and a progress bar before the site reveals itself
- **Dark / Light theme toggle** — instantly switch between a moody dark UI and a clean light UI
- **Glitch text effect** on the hero title for a techy, futuristic feel
- **Typing animation** — hero headline types itself out on load
- **Scroll-triggered fade-in animations** for every section using `IntersectionObserver`
- **Staggered reveal animations** for skill cards, project cards, and the education timeline
- **Magnetic buttons** — buttons subtly follow your cursor on hover
- **3D tilt effect** on project cards that responds to mouse movement
- **Flip-card project showcase** — hover a project card to flip it and reveal details, tech stack, and links
- **Scroll progress bar** fixed at the top of the page
- **Infinite scrolling ticker** showing rotating roles/skills in the hero section
- **Fully responsive** — optimized layouts for mobile, tablet, and desktop

### 🧩 Sections
| Section | Description |
|---|---|
| **Hero** | Intro, tagline, availability badge, CV download, social links |
| **About Me** | Background, bio, and quick facts |
| **Skills** | Grid of technical skills with hover effects |
| **Projects** | Flip-card showcase of 6 featured projects with live demo & GitHub links |

## 🛠️ Tech Stack

- **HTML5** — semantic structure
- **CSS3** — custom properties, gradients, animations, keyframes, responsive grid/flexbox layouts
- **Vanilla JavaScript** — DOM manipulation, `IntersectionObserver` API, event-driven interactions (no libraries/frameworks)
- **Formspree** — handles the contact form submissions
- **Vercel** — hosting & deployment

## 🚀 Running Locally

Since this is a static site with no build step, you can run it directly:

```bash
git clone https://github.com/Huzaifaahmedbhutto/portfolio.git
cd portfolio
```

Then simply open `index.html` in your browser, or serve it locally:

```bash
# Using Python
python -m http.server 8000

# Using Node (with npx)
npx serve .
```
